# Eigenaars eigen v1-screenshots

Plaats hier de telefoonscreenshots van de live v1-app die de eigenaar zelf
maakt — via GitHub's "Add file → Upload files" op de
`docs/v1-look-and-feel-pariteit`-branch. Deze vullen de zelf-gemaakte
referentiescreenshots in `docs/v1-screenshots/` (één niveau hoger) aan met
echte gebruikersinteracties (bijv. de live wissel-flow-highlighting) die
niet zomaar geautomatiseerd te reproduceren waren.

Zie `docs/v1-look-and-feel-pariteit.md` voor de context.
